# PlanBoard

Planning uses five 480-minute workdays. Each operation is nonpreemptive, must fit one shift, obey predecessor completion, compatible resources and blackouts. Never claim global optimality. Run unittest and browser QA, document observed results in docs/QA.md and record unfinished scope before committing. Never expose real customer data or credentials. Keep the UI plain and accessible.
