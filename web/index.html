Jak PlanBoard funguje

Python a SQLite na místním serveru, jednoduché HTML/CSS/JavaScript rozhraní. Bez externího API a bez AI výpočtů. Plánovač řadí celé zakázky podle priority, termínu a ID a hledá nejbližší volný interval. Výsledek ověřuje další kontrolor. Heuristika nezaručuje optimální řešení.

Každá směna má nejvýše 480 minut. Operace se nepřerušuje, musí se vejít do jedné směny a navazovat na předchozí. Časy a zpoždění se měří v pracovních minutách; noci a víkendy se nezapočítávají. Pokud se nevejde celá zakázka, nezabere částečně kapacitu ostatním. SQLite ukládá vstupní scénáře do ignorovaného data/; po otevření se plán znovu počítá.
